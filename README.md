# ~/.dotfiles 💾

Personal dotfiles. Uses [`tuckr`]("https://github.com/RaphGL/Tuckr") as the dotfile manager.

## Setting things up 🧑‍💻

1. Install `tuckr`.
2. Clone the dotfiles repository under `~/.dotfiles` (Linux, macOS).
3. Run `tuckr status` to view the current dotfiles symlink status.
4. Run `tuckr set \*` to set all the dotfile symlinks + run hook scripts.
5. Finally, run `tuckr status` to validate symlinks.
